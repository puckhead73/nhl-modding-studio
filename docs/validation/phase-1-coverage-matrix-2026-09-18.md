## Vocabulary (exactly one per cell)

| Level | Meaning |
|---|---|
| **impl+tested** | the Studio operation exists and a named automated case executed and asserted it on that family (synthetic or committed-anchor data) |
| **impl, test missing** | the code path exists for the family but no automated case exercises it there |
| **not impl** | no Studio operation exists |
| **research unknown** | the game-side facts needed to build or scope the operation are not established |
| **n/a (evidence)** | evidence-backed not applicable, with the evidence named |
| **blocked** | implementation is blocked; the blocker is recorded |

**R1 reconciliation (19 September, [OVERNIGHT-DEV-R1](overnight-development-2026-09-19-review-r1.md) F3,
record [overnight-dev-r1-corrections-2026-09-19.md](overnight-dev-r1-corrections-2026-09-19.md)):** cells
