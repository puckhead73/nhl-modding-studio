## Implemented

- NHL07-specific Equipment tab with role-specific equipment, appearance, portrait and commentary sections. Large catalogues are searchable. Choices use original-database donor names rather than unverified later-game brand/color labels.
- Skaters: stick, skates, tape, helmet/variation, gloves, visor, visor color, pants, neck protection, shoulders, jersey tuck and sock tuck. A field with only one original combination offers no invented alternatives.
- Goalies: stick, skates, tape, mask, pads, blocker and trapper. Each gear selector preserves the matching custom flag from its original combination; these flags are not independent guesswork controls.
- Head selection copies head, skin and both eye values together. Skin and eyes can subsequently be selected independently from original values. Portraits are independent. Commentary selection copies active/default references together.
- All choices are validated server-side against the immutable project-original database, limited to the applicable role for equipment. Imported unknown combinations stay visible and unchanged until deliberately replaced. The catalogue uses original names, even if the user renames players.
- Shared assets are never overwritten by an assignment. The original combination's usage count is displayed. This is a combination count, not a count of physical files.
- Immediate selection feedback, failure rollback, serialized writes and existing Save/Undo/Build barriers. Assignment reads/writes and the player detail command run on the native blocking pool, not the window thread.
- Overview groups NHL07 assignments under Equipment, Appearance, or Portrait and commentary, uses friendly field labels and donor/value summaries, links back to Equipment, and supports atomic linked reverts. Reverting any head/complexion field restores that player's original head/skin/eyes together. Audio and associated gear flags likewise revert together. Unrelated edits remain.
- Existing save/autosave, archive and build systems carry these database edits without an additional asset file payload.
