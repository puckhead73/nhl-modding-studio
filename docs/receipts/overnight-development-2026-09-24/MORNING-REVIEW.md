## Notes for the user

- **Weight was wrong on PS4 and NHL 08 until this morning** (package 11): every PS4 player showed
  30 lb heavier than the game's roster and a staged weight would have been written 30 lb light;
  NHL 08 the other way. If you staged a weight on a PS4 title in an earlier session, re-check it.

- **Equipment model names now appear only on NHL Legacy** (package 21): the stick / glove /
  helmet / skate / visor / tape names came from Legacy's textures and never belonged to the other
  titles; those titles now show the stored number and say why. Nothing you had staged changes.
- **How Studio decides a title's weight / rating encoding changed this afternoon** (package 20): it
  used to look at the numbers in the file, which an edited roster could fool; it now reads the
  title's schema. Nothing you see should change on a stock roster. If a project was opened under
  the wrong title, the weight / rating / birth-date / cap-hit cells now refuse to write and say why.
- The texture Replace dialog now proves, at write time, that the file it writes is the file it
  showed you — if anything moved underneath it, it stops and shows a fresh plan instead of writing.
- The PS4 and gen7 speech previews are **diagnostic**: they decode with a standard MP3 decoder from
  the research's measured grammar, and the label names the one thing nobody has established — how
  the first few dozen milliseconds are meant to start. Your ear is the next measurement.
- PS3 NHL 12 / 13 kit textures inside the render archives can now be replaced through the archive
  route (the earlier "no encoder" blocker turned out not to apply — those members use the
  compression Studio already writes). Whether the console accepts a rewritten archive copy is the
  runtime question above.
