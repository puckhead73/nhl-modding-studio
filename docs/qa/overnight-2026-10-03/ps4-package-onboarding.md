# PS4 package onboarding qualification

Studio now provides an optional base-PKG extraction route in onboarding. It starts a background job, uses a fresh destination, reports progress and cancellation through the existing extraction job API, validates the selected game's SFO and executable, checks archive tables and payload bounds, then hands the copied game folder to archive extraction and discovery. Existing output directories and patch/DLC packages are refused. Cancellation kills and reaps the owned helper; partial output is retained and never offered as a completed import. Output links/reparse points are rejected before discovery, and validation also observes cancellation.

The selected helper is the standalone [shadPS4Plus PKG Extractor 1.1](https://github.com/AzaharPlus/shadPS4Plus/releases/tag/PKG_EXTRACTOR_1_1). QA uses the upstream Windows ZIP with SHA-256 A6A6DEE84C1283949245C868E580FF8D0049D0E73DF9DE3096460EE26C6F04D7, with its two adjacent DLLs. Studio calls the executable directly with separate arguments; it does not run install_pkg.bat or change emulator settings. Exit code zero alone is not accepted as success.

Validation:

- Real Registry package job on NHL20 passed in 191.23 seconds: 50 files / 30,594,149,011 bytes in F:/TEMP/nhl-studio-overnight-20261003/nhl20/pkg-onboarding-job-1. Source length and modification time remained unchanged; trying the same destination again was refused. Receipt: nhlms-package-job-receipt.json inside that owned output.
- Domain tests pass: invalid input, missing helper, cancellation before output creation, existing-file preservation, truncated archive payload refusal, cancellation and timeout with child reaping. The subsequent pre-discovery tree validation change passes the same suite plus tree counting and cancelled-validation checks (2 tests, 1 deliberately ignored subprocess fixture).
- Nineteen focused onboarding/component tests pass, including package completion handoff, packed game_dir fallback, cancellation/failed states, busy controls and stale callback protection. Frontend production build and off-main command guard pass.
- NHL18 and NHL20 standalone package outputs were independently compared with installed files before this integration; all game archives match those installations. Small npbind.dat differences remain recorded in the title reports.

Release assembly now accepts the qualified helper bundle, includes its exact program and Crypto++ sources plus runtime notices, and validates pinned hashes and DLL imports. The 608,721,252-byte QA archive includes it at tools/pkg-extractor; archive integrity and extracted-resource checks pass. Missing DLL/source/notice and changed-binary regression checks pass. This is an internal review archive, not a published release. Native UI qualification remains pending; desktop control later recovered but the user currently needs the second monitor undisturbed. No package job or launch result establishes edited gameplay.
