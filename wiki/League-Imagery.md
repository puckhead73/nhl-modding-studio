# League Imagery

**Game Database › Leagues › presentation imagery** shows the league-keyed artwork families the game ships, playoff-tree logos, trophies and, on PS4, the registry types, with a preview and a replace action for each file. It is a read-and-replace page: it never edits the database.

The card is titled **League presentation imagery** with the subtitle "N league-keyed families on <game> (<platform>) — binding read from <registry>". Each family has a label, a description and either "Screens: …" (the game screens that reference it) or "No screen references this family in UI text."

The table lists id, file and preview. Where a French twin of an image exists it is shown with "+ French twin" (or "(not extracted)" when the file is missing). Buttons:

- **Replace…** writes an edited image into the loose file, keeping a `.bak`.
- **Replace French…** does the same for the French variant.
- **Replace in archive…** and **French in archive…** (PS4) rewrite the member inside the packed archive through the copied-target save, because the PS4 game reads the archive, not loose files.

Both dialogs are described under [File Browser](File-Browser) (loose replace) and [Project Overview and Building](Project-Overview-and-Building) (archive members and the copied-target save).

When the title has no inventory the page says "No league-keyed imagery inventory for this title." and "The inventory covers Xbox 360 NHL 07–Legacy, PS3 NHL 08–Legacy and PS4 NHL 15–21." The link to this page is hidden in the Save Editor.
