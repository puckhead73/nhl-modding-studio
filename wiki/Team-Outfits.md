# Team Outfits

**Assets › Team Outfits** exports every team's jersey, pants and socks textures in one run, named by team. "Every team's jersey, pants and socks — colour, spec, normal and number/name maps — written out as PNGs and named by the team they belong to."

**Export all team outfits…** asks for a folder and writes `jersey/`, `pant/` and `sock/` subfolders. File names start with the team, for example `detroit_red_wings_jersey_0_0_cm.png` on older titles or `detroit_red_wings_jersey_rbk_home_cm.png` on PS4, which keeps each jersey's variant name. The run decodes every team and "can take a little while".

The **Last export** card reports teams, size and the number of jersey, pant and sock maps, with any failures. If nothing was written the page says where it looked and why: no teams resolved from the database, or teams resolved but no textures found, which usually means the art is not extracted or the title stores outfits in a layout the exporter does not handle yet.

The page shares the Assets gate described under [Player Art](Player-Art). To replace a single kit's textures, use the team's **Uniforms** tab ([Uniforms and Nameplates](Uniforms-and-Nameplates)).
