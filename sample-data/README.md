# sample-data

Synthetic and redacted fixtures **only**. This is the home for small, safe test data used by the
Rust core and UI.

## Rules

- **No copyrighted EA data, ever.** No real game databases, saves, or extracted assets.
- Real (locally held) game files used for development must live **outside** the repo, or under
  `sample-data/real/` and `fixtures/private/`, both of which are git-ignored.
- Anything committed here must be either generated by us or fully redacted/synthetic, and small.

See [.gitignore](../.gitignore) for the enforced exclusions and
[CLAUDE.md](../CLAUDE.md) for the hard rules.
